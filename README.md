## O que eu faço

- **[SaaS sob medida](https://ignotti.com/servicos/saas):** sistemas, painéis e ferramentas internas que trocam planilha e trabalho manual por um sistema web.
- **[Sites](https://ignotti.com/servicos/sites-institucionais):** site institucional ou landing page para o seu negócio, do layout ao site publicado.
- **[Servidores de jogo](https://ignotti.com/servicos/jogos):** plugins, mods e sistemas para Minecraft e Hytale, feitos por quem mantém o próprio servidor no ar.
- **[Automações](https://ignotti.com/servicos/automacoes):** bots de Discord, integrações e atendentes com IA que trabalham sozinhos.

## Ferramentas

- **Web:** TypeScript, React, Next.js, Astro, Tailwind CSS, Node.js, Fastify
- **Dados:** PostgreSQL, Drizzle, Prisma, Redis, SQLite
- **Infra:** Cloudflare, Docker, Vercel
- **Jogos:** Java (Paper, Geyser e servidor do Hytale), C# com Unity
- **Qualidade:** Vitest, Playwright, JUnit, acessibilidade e Lighthouse medidos nos projetos web
